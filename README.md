# 📖 Overview

Spotify Clone is a modern music streaming web application inspired by Spotify.

The project allows users to search songs, explore artists, view albums, and play music through an intuitive and responsive interface.

This project was built to improve JavaScript fundamentals while implementing real-world UI components and API integration.
